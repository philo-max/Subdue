## 💻 1. 源代码材料排版规范与内容精选

### 📐 官方格式排版要求
*   **页眉**：每页右上角写上软件全称及版本号（如：`Subdue 订阅管理软件 v0.2.0`），并加一条横线。
*   **页脚**：必须居中显示页码，格式为 `第 X 页` 或 `第 X 页 共 60 页`（页码必须连续且严格等于 60 页）。
*   **字体**：推荐使用等宽字体（如 `Courier New`）或五号宋体，确保代码排版整齐。
*   **行距与行数**：单倍行距，**每页必须不少于 50 行**（通常设为 50~55 行，空行和多行纯注释不计入行数）。
*   **注释与敏感信息**：
    *   代码中**严禁**出现 `Todo`、`Draft`、`Demo`、`Test`、`Fixme` 等显得不完整的开发标记。
    *   **严禁**出现其他无关公司的版权声明（如 `Copyright by (其他公司)`）。
    *   建议清除大量的英文注释或占位符号，保留少量的中文业务注释以增强原创性外观。

## 📖 2. 软件用户操作手册大纲指南

国家版权局要求操作手册能够使人“看图即懂”。以下是为您整理的 **Subdue 用户操作手册大纲**，您可以根据各部分的提示，在本地运行 Web 端和 Mobile 端并截图，填入文档中。

### 📑 目录

#### 第一章 系统概述
*   **1.1 软件定位**：无广告、本地优先的多平台订阅账单追踪系统。
*   **1.2 运行环境要求**：
    *   PC 端：现代浏览器（Edge, Chrome, Safari 等），需开启本地 IndexedDB 存储。
    *   移动端：支持 iOS 15+ 或 Android 8+ 的智能手机。

#### 第二章 安装与部署运行
*   **2.1 PC 网页端启动**：展示如何通过 `npm run dev` 运行，并在浏览器打开 `http://localhost:5173`。
*   **2.2 移动端启动**：展示如何通过 `npx expo start` 启动并真机扫码打开。

#### 第三章 Web 客户端功能操作说明（含图）
*   **3.1 订阅统计看板 (Dashboard)**
    *   【操作步骤】：打开应用即展示。
    *   【功能说明】：统计本月预计支出、折合年付支出、多币种折算比例，以及到期天数雷达（展示 7 天内即将扣款的订阅）。
    *   【截图提示】：截取 Web 端首页仪表盘及环形比例图。
*   **3.2 手动记账与智能匹配**
    *   【操作步骤】：点击 Web 右侧的 “+ 添加订阅” -> 输入名称（如 "Netflix"） -> 触发自动补全 -> 确认保存。
    *   【截图提示】：截取侧边栏添加表单，模糊输入匹配时的下拉列表。
*   **3.3 账单 CSV 智能分析导入（核心亮点功能）**
    *   【操作步骤】：点击系统设置 -> 选择 “导入账单 (CSV)” -> 上传从微信/支付宝导出的 CSV 账单 -> 系统弹窗展示识别出的周期性扣款 -> 用户勾选并点击“确认导入”。
    *   【截图提示】：

*   **3.4 多币种汇率管理**
    *   【操作步骤】：设置 -> 选择主结算货币（CNY/USD） -> 点击“同步最新汇率”。

#### 第四章 Mobile 客户端功能操作说明（含图）
*   **4.1 移动端看板与到期消息通知**
    *   【截图提示】：手机端 Dashboard 列表，加急红色高亮扣款卡片。

    *   【操作步骤】：打开手机助手 Tab -> 在 PC 设置面板中获取 6 位局域网同步码 -> 在手机端输入配对码 -> 点击配对 -> 建立安全加密通信并自动合并双端账单。
